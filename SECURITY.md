# Security reporting

Do not put exploit details, credentials, tokens, private songbooks, or personal data in public issues or pull requests.

If GitHub displays a **Report a vulnerability** option under this repository's Security tab, use it for a private report. Its availability is not guaranteed. Otherwise, contact the owner through an already established private channel to arrange secure reporting. If none is available, open a public issue asking only how to contact the maintainer privately, without disclosing the vulnerability.

Include the affected version/commit, impact, and minimal reproduction privately once a channel is agreed. No response-time commitment or supported-version policy is currently defined.
